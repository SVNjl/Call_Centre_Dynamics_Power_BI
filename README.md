Objective : To do the analysis of a Call Center dataset and add necessary KPIs to provide valuable insights and recommendations to enhance customer support services, improve response times and optimize resource allocation.

Methodology :-
1. Imported and cleaned raw call center dataset using Power Query editor, ensuring accuracy and relevance.
2. Engineered key metrics including daily call volume, geographic distribution, top call reasons, sentiment analysis, channel distribution, etc.
3. Developed a new table (Date) and the required measures (Total Calls, Total Call Duration, Avg Call Duration, Response Time %, etc.) using DAX for enhanced time analysis, enabling robust reporting capabilities.
4. Used different types of customized visualizations to visualize the intricate relationships among the various parameters/columns and enabled user driven parameters for visualization.
